# lotabin media folder

## Current logo path

The current source logo is a PNG provided by the client and should live at:

```txt
public/media/lotabin-logo.png
```

Use this logo in the navbar and footer with meaningful alt text:

```txt
alt="lotabin logo"
```

Do not crop, stretch, distort, recolor, trace, redesign, or add heavy glow, bevel, shadow, or cheap effects to the logo. Preserve the source aspect ratio. If the light logo background does not blend directly with the cinematic dark site, place it inside a tasteful dark or ivory surface instead of editing the logo itself.

## Future preferred logo assets

A transparent PNG or SVG may replace this file later if provided. When a higher-quality transparent logo is available, keep the same naming convention or update `brand.logoPath` in `lib/siteData.ts` intentionally.
